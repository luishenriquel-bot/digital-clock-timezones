# Digital Clock Time Zones

A simple web app that displays the current time in multiple time zones in real time.

## Features

- Live digital clock
- Multiple time zones
- Clean modern UI
- Automatic updates every second

## Included time zones

- UTC
- New York (America/New_York)
- London (Europe/London)
- São Paulo (America/Sao_Paulo)
- Tokyo (Asia/Tokyo)
- Sydney (Australia/Sydney)

## Run locally

Open `index.html` in a browser.

## Files

- `index.html` – page structure
- `style.css` – styling
- `script.js` – time logic
